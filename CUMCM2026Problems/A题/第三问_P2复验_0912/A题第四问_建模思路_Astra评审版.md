# 8. 候选方案 A：归一化坐标 / 准 Lagrangian 形式【当前更推荐】

如果将 \(\xi=r/R(t)\) 视为跟随材料层的坐标，则在均匀收缩假设下：

\[
r=R(t)\xi
\]

且：

\[
\frac{\partial}{\partial r}
=
\frac1{R(t)}
\frac{\partial}{\partial\xi}
\]

对于随固体骨架运动的物质导数：

\[
\frac{D}{Dt}
=
\frac{\partial}{\partial t}
+
v_r\frac{\partial}{\partial r}
\]

在固定 \(\xi\) 下有：

\[
\frac{D U}{Dt}
=
\left.
\frac{\partial \widehat U}{\partial t}
\right|_\xi
\]

因此候选温度方程为：

\[
\boxed{
\rho(C)c_p(C)
\frac{\partial T}{\partial t}
=
\frac{1}{R^2(t)\xi}
\frac{\partial}{\partial\xi}
\left[
\xi k(C)
\frac{\partial T}{\partial\xi}
\right]
}
\]

候选水分方程为：

\[
\boxed{
\frac{\partial C}{\partial t}
=
\frac{1}{R^2(t)\xi}
\frac{\partial}{\partial\xi}
\left[
\xi D(C,T)
\frac{\partial C}{\partial\xi}
\right]
}
\]

这里时间导数理解为固定 \(\xi\) 的材料层导数。

### 重要优点

这样：

- 计算域始终固定：
  \[
  0\le\xi\le1
  \]
- 收缩影响通过：
  \[
  R^{-2}(t)
  \]
  进入扩散尺度；
- 无需在变换后的方程中额外写显式：
  \[
  v_r\frac{\partial U}{\partial r}
  \]
  因为它已被材料坐标吸收。

# 9. 候选方案 B：动态物理网格【实现上与 A 对应】

> 每个时间步重新计算圆柱当前半径，并相应重新计算均匀有限体积网格的 \(\Delta r\)。

因此实现时可保持固定的归一化网格：

\[
\xi_{i+1/2}
=
\frac{i}{N}
\]

\[
r_{i+1/2}(t)
=
R(t)\xi_{i+1/2}
\]

以及：

\[
\boxed{
\Delta r(t)=\frac{R(t)}{N}
}
\]

第 \(i\) 个环形控制体：

\[
V_i(t)
=
\pi L
\left[
r_{i+1/2}^2(t)
-
r_{i-1/2}^2(t)
\right]
\]

界面面积：

\[
A_{i+1/2}(t)
=
2\pi Lr_{i+1/2}(t)
\]

内部导热/扩散通量继续使用调和平均。
