# 第三问交付与复现

## 给文字手

- `第三问结果与分析.md`：问题分析、终止判据、表5、数值比较与模型局限。
- `results/result3.xlsx`：题目要求的逐60 s、径向逐0.1 cm水分浓度。使用官方示例模板扩展后的Sheet1，单元格为数值，保留四位小数。
- `results/表5_水分浓度.xlsx`、`.md`、`.tex`：论文要求的每6 h、每0.5 cm及结束时刻的简表。
- `figures/`：三张核心图，各有PDF、SVG、300 DPI PNG与灰度预览。
- `results/计算摘要.json`、`计算方案比较.csv`：未舍入的事件区间、各计算设置、边界敏感性与输出口径。

均值延拓是主方案。结果表中的最后一行按60 s网格略晚于实际终止时刻；论文表5单独列精确报告时刻。显示为0.1500的单元格不等于未舍入值大于等于0.15。

0.001 s是局部事件定位区间宽度；时间步与网格误差见实际比较，不能把事件定位精度当作整体预测精度。第一、二问文件和原始题目附件保持只读。

## 复现方式

在当前目录运行：

```sh
/opt/anaconda3/bin/python reproduce_q3.py
```

该命令首先核对求解器、环境数据和第二问结果表的哈希。已存在且匹配的计算缓存会被复用；不存在或不匹配的情况会实际计算，再重建Excel、表5、图和文字分析。缓存重建不冒充重新执行偏微分方程计算。

要重新运行全部计算：

```sh
/opt/anaconda3/bin/python reproduce_q3.py --recompute
```

单独重算主方案：

```sh
/opt/anaconda3/bin/python solve_q3.py --mode case --n 3200 --dt 0.5 --extension mean --label mean_n3200_dt0p5
```

前3 h的完整内部状态缓存在 `runs/prefix_n*_dt0.0625.npz`。它们来自相应网格的原始初态计算；程序核对来源哈希后复用，不从21列结果表反推内部网格。

`solve_q3.py` 的 `--end` 仅对smoke模式生效；case模式以全域阈值事件结束，并设14天保护上限。该上限不是提前指定的烘干预测时长。

## 使用边界

第三问继续使用第二问确定的有效物性模型，不加入收缩、潜热或新的经验拟合模型。图和数值均来自本次真实运行。按照用户节省用量的要求，保留必要回归、终点收敛和两种延拓比较，未额外扩展九图或其他物理模型。
