# 第四问符号与含义

| 符号 | 含义 | 单位/说明 |
| --- | --- | --- |
| \(t\) | 从原始初态开始的烘干时间 | s；论文时长换算为h |
| \(R(t)\) | 题给半径数据插值得到的表面位置 | m，输入数据由cm换算 |
| \(R_0\) | 初始半径 | 0.02 m |
| \(r\) | 当前物理半径 | m，结果表按cm标注 |
| \(\xi=r/R(t)\) | 跟随均匀径向收缩的材料坐标 | 无量纲 |
| \(v_r=(\dot R/R)r\) | 假设的材料径向速度 | m/s；由均匀缩放假设给出 |
| \(C\) | 单位干物质所含的水分质量 | kg/kg，干基 |
| \(\rho_d\) | 干物质质量除以当前体积 | kg/m³；守恒推导辅助量，不与题给密度混同 |
| \(m_{d,i}\) | 第i个随材料移动的控制体中的干物质量 | kg；在该模型下恒定，绝对值无需求解 |
| \(\rho(C)\) | 题给有效热物性密度 | kg/m³，用于蓄热系数 |
| \(c_p(C)\) | 题给比热容 | J/(kg K) |
| \(k(C)\) | 题给热导率 | W/(m K) |
| \(D(C,T_K)\) | 有效水分扩散系数 | m²/s |
| \(T\)、\(T_K\) | 局部摄氏温度、绝对温度 | ℃、K；\(T_K=T+273.15\) |
| \(T_\infty,C_\infty\) | 烘房温度、等效外界水分浓度 | 沿用第三问的环境处理 |
| \(T_s,C_s\) | 当前真实表面的状态 | 由Robin边界反算 |
| \(w_i\) | 归一化环形控制体的固定几何权重 | \((\xi_{i+1/2}^2-\xi_{i-1/2}^2)/2\) |
| \(V_i(t),A_f(t)\) | 当前控制体体积、界面面积 | m³、m² |
| \(\boldsymbol j_w\) | 相对干物质的有效水质量通量 | \(-\rho_dD\nabla C\)，用于守恒解释 |
| \(C_{\max}\) | 整个当前半径内的最大含水率 | 检查内部、轴心和表面 |
| \(t_{\rm dry}^{(4)}\) | 首次全域含水率低于0.15的时间下确界 | 尚未计算；有限报告时刻按实际数值规则确定 |
